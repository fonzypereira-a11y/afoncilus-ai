AFONCILUS AI
Protótipo web criado para Afonso.

Inclui:
- interface responsiva para PC/iPad;
- chat;
- histórico local;
- botão de pesquisa Web;
- geração de imagens experimental.

Atenção: os endpoints públicos de IA são externos e podem ter limites, indisponibilidade ou alterações. Não há garantia de IA ilimitada gratuita. O site não deve ser usado para contornar filtros, MDM ou políticas de uma escola/rede.

Para testar:
1. Abrir index.html num browser.
2. Para usar no iPad, publicar os ficheiros num alojamento estático permitido (por exemplo, GitHub Pages ou Cloudflare Pages).
